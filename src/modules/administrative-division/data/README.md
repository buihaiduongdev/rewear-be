# Vietnam administrative division snapshot (GHN 3-level)

This module bundles a versioned three-level Vietnam administrative division snapshot (`ghn-divisions-snapshot.json`) aligned with GHN master data (Province, District, Ward) so API requests do not depend on external roundtrips for standard shipping lookups.

- Scope: 3-level administrative units (Provinces with GHN `ProvinceID`, Districts with GHN `DistrictID`, Wards with GHN `WardCode`).
- Source: GHN Open API v2 master data synchronization.
